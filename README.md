# Projeto Integrador – Adoção de Animais

O projeto consiste no desenvolvimento de um site voltado à adoção de animais, com o objetivo de conectar animais que precisam de um lar a pessoas interessadas em adotá-los.  
A plataforma permitirá visualizar animais disponíveis para adoção, com informações como nome, idade, porte e características.  
O objetivo é incentivar a adoção responsável, combater o abandono e proporcionar uma oportunidade para que cães e gatos encontrem um novo lar cheio de carinho.
